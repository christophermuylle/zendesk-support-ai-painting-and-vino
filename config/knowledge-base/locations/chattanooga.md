# Chattanooga, TN

Status: OPEN for private events as of 2026-10-03 (confirmed by Christopher).

Until 2026-10-03 this file said "coming soon - not yet operating", which is
what the AI told anyone who asked. That is no longer true for private events.

## Private events
Available for birthdays, bachelorette parties, corporate team-building,
fundraisers and kids' parties, on the same terms as the other launched
locations - see shared.md's Private events section for the full pricing table
and reply structure.

Minimum group size: 8 guests. ASSUMED, not confirmed - it is the default, and
only Tucson and Sacramento run a 10-guest minimum. Worth confirming with
Christopher.

Per-person rates are shared.md's default table - Standard 45/40/35,
Corporate 50/45/40. shared.md names Kansas City and San Francisco Bay as the
only locations with their own tiers, so Chattanooga sits in the default group.

Area covered: Chattanooga, Hixson, Collegedale, Ooltewah, Ringgold, Fort
Oglethorpe, East Ridge, Soddy-Daisy, Signal Mountain, East Brainerd, Dalton
and Rossville (Christopher, 2026-10-03). The metro straddles the state line -
East Ridge and Signal Mountain are Tennessee; Ringgold, Fort Oglethorpe,
Dalton and Rossville are Georgia.
