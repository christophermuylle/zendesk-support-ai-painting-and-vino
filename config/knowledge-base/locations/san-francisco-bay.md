# San Francisco Bay Area, CA

Source: paintingandvino.com/paint-and-sip-san-francisco-bay/ - confirm
current before relying on it.

## Pricing
Range: $25-$50, with some premium events up to $60.

## Booking
Book through the event listing's "Get Tickets" button - each event has its
own registration page. Seating is limited per class, so booking in advance
is recommended.

## Venues (examples - always confirm the specific one on the event listing)
Humble Sea Brewing Co. (Pacifica), Barebottle Brewing Co. (San Francisco,
Menlo Park), Laughing Monk Brewing (Scotts Valley), Grand Bay Hotel
(Redwood City), JTown Pizza (San Jose), Out of the Barrel Taproom (San
Carlos).

## Private events
Available for birthdays, bachelorette parties, etc. - direct the customer
to "request a quote." No fixed minimum group size found on the location
page.

## What's included
Canvas, paints, brushes, and an apron. Food/drinks available for purchase
but not included.
